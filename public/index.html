About this group

This is a private family group text. It is used only for conversational family chat among about 25 family members. There is no marketing, no advertising, and nothing for sale.

Messages sent to the group number are relayed to the other members so everyone can stay in the same conversation. The program uses the number (620) 634-1542.

How to join

Members are added only after they personally give consent to Jack Wolcowitz. You can do that in either of these ways:

  • Tell Jack verbally that you want to be included, or
  • Text JOIN to (620) 634-1542.

No one is added automatically, and no one is added on someone else’s behalf without their own consent.
